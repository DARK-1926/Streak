# Email Assistant\n\n## Overview\nA production‑grade microservice that receives raw email data, uses an LLM to generate a concise summary and a priority score, and persists the result for downstream workflow automation.\n\n## Architecture\n- **FastAPI** – request handling and OpenAPI docs\n- **Celery + Redis** – asynchronous processing so the API stays responsive\n- **PostgreSQL** – durable storage of processed emails\n- **LLM Client** – pluggable interface to any OpenAI‑compatible endpoint\n\n## Quick Start\n```bash\n# set environment variables (or use a .env file)\nexport LLM_API_KEY=...\nexport POSTGRES_DSN=postgresql+psycopg2://user:pass@db/emaildb\n\ndocker compose up -d  # includes db, redis, and the service\n```\n\n## API\n### POST /process\nAccepts JSON with `message_id`, `sender`, `subject`, `body`. Returns immediate placeholder; results are stored in DB.\n\n### GET /health\nLiveness probe.\n\n## Testing\n```bash\npytest\n```\n\n## Extensibility\n- Swap `LLMClient` for a local model via `vLLM` or `Ollama`.\n- Add webhook callbacks to notify downstream systems when processing completes.\n
